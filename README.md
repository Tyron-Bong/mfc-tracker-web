# MFC Tracker web app

The recording and results page for the MFC Tracker (a foot-mounted tracker for minimum foot
clearance, a final year project at Monash University Malaysia). Open it in Chrome on Android,
Windows or macOS:

https://tyron-bong.github.io/mfc-tracker-web/

This repository is generated: the page is built from the project's `web/` folder and the
receiver's Python by `tools/publish_web.py` in the project. Do not edit it here.
